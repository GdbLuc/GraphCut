# GraphCut
Simple yet complex grapher, tend to be an equivalent of vim for graph creation
## Shortcuts :
right click to create/delete a node<br>
drag with left click to move around<br>
left click on node to select it<br>
, : target last selected node<br>
; : target and unselect last selected node<br>
. : unselect last selected node<br>
! : unselect all nodes<br>
? : select all nodes<br>
(if no nodes are targeted, all selected nodes will be)<br>
m : change targeted node from an ellipse to a rectangle, or from a rectangle to an ellipse<br>
c then 'r g b\r' : change targeted nodes color to r, g, b<br>
w then 'x y\r' : change targeted nodes dimension to x, y<br>
r then 'x y\r' : move targeted nodes at position x, y<br>
t then 't\r' : write the text t on targeted nodes<br>
